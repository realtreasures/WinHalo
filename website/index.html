在 Windows 上使用 WinHalo

目前可从源码构建。可下载的安装包或便携包发布后，可在 GitHub Releases 获取。

查看 GitHub Releases 查看构建说明
  1. 构建后运行 WinHalo.exe。
  2. 滑过屏幕顶部的待机胶囊。右击可打开设置。
  3. 在支持 Windows 系统媒体控制的播放器中播放音乐，再点击胶囊展开。
支持哪些 Windows 版本？

项目面向 Windows 11 和 Windows 10 1809 及以上版本。Windows 10 的实机兼容性仍在验证，桌面模糊需要受支持的 Windows 11 环境。

为什么胶囊没有显示音乐或聊天消息？

音乐软件需要向 Windows 注册系统媒体会话。聊天功能需要安装通知组件、开启 WinHalo 的聊天消息开关并授予通知读取权限。QQ 已实测，微信仍待实机验证。查看通知接入说明

有哪些快捷键？

Ctrl + Alt + Space 展开或收起播放器。
Ctrl + Alt + I 显示或隐藏灵动岛。
Ctrl + Alt + Q 退出 WinHalo。
