# 独立设置窗口

右击横线或胶囊直接打开设置；托盘菜单也保留入口。设置为普通可输入的窗口，重复打开复用同一实例，关闭后 WinHalo 继续运行。无音乐时仍只有横线与时钟胶囊，左击时钟不会打开面板。

外观支持胶囊和播放器缩放、基础宽高、展开宽高、位置偏移、字体、显示器及待机横线长度。数字可直接输入或使用加减按钮，失去焦点或按 Enter 提交，即时应用并原子保存。调整紧凑尺寸会短暂显示胶囊预览。播放器内容按比例居中，封面和图标不拉伸。

行为支持真实开机启动、五秒空闲收起、全屏隐藏、右键长按拖动、状态通知、音量 / 亮度快捷调节、链接确认、设备活动提示和中英文切换。短按右键打开设置，按住至少 400 ms 后拖动保存位置。胶囊上滚轮调音量，Shift + 滚轮调亮度；禁用系统控制后提示中的音量按钮也不可操作。

“恢复默认”仅恢复应用偏好，不改变 Windows 中实际的开机启动注册。配置升级至版本 3，旧设置保留系统偏好，并将旧嵌入设置面板的高度迁移为播放器默认 200 DIP。

剪贴板链接和设备活动提示默认关闭。链接只接受 HTTP(S)，先显示确认，点击“打开”后才启动浏览器；按下和松开必须属于同一条链接提示，避免提示替换造成误打开。设备状态仅使用 Windows 提供的活动元数据，不采集音视频。状态通知限 WinHalo 自身，不接收其他应用的 Windows 通知。

## 滚动与绘制修复（2026-10-19）

快速滚动时，原实现逐个移动并重绘子控件，旧像素复制与新布局交错，造成残影和控件重叠。现在合并连续滚动请求，批量定位全部控件，禁止复制旧位置像素，完成布局后统一重绘父窗口与子控件。窗口大小和 DPI 变化也只执行一次完整布局。

圆角、开关、加减图标与焦点边框改用 Direct2D 抗锯齿绘制，并复用绘图目标和离屏缓冲。原生输入框和下拉框继续支持输入、键盘操作与辅助功能，启用 Common Controls v6 样式。鼠标点击导航只显示选中背景；使用 Tab 时显示蓝色圆角焦点提示，替代黑色虚线框。

- 主程序 x64 Debug / Release 构建通过。
- `tests/settings_render_smoke.py` 在真实桌面 150% 缩放下通过：快速滚轮、滚动条拖动、重复导航点击、控件内容与位置、鼠标焦点提示和 Tab 切换。五组控件区域在强制重绘前后均为零像素差异；GDI 对象数从 65 到 67，1.2 秒静止采样的 CPU 时间为 0 ms。该采样不代表长期功耗。
- `tests/WinHalo.SettingsDpiTests.vcxproj` 通过：自有像素缓冲验证圆角的混色抗锯齿；四种 DPI 下模拟鼠标 / Tab 消息，验证鼠标无焦点边框、键盘显示蓝边且无黑色虚线；数值提交与中英文字体切换保留编辑值。另覆盖 100 / 125 / 150 / 200% DPI 模拟、200 次上下滚动往返、46 个原生控件排列、两次窗口创建与关闭及 GDI 资源释放。模拟消息不等同于实际多显示器缩放切换。

实屏回归截图：`artifacts/settings-render-wheel-moving.png`、`artifacts/settings-render-thumb-moving.png` 和 `artifacts/settings-render-stable.png`。

```powershell
MSBuild.exe .\tests\WinHalo.SettingsDpiTests.vcxproj /p:Configuration=Debug /p:Platform=x64
& .\x64\SettingsDpiTests\Debug\WinHalo.SettingsDpiTests.exe
python .\tests\settings_render_smoke.py .\x64\Release\WinHalo.exe
```

实屏脚本会短暂移动鼠标，结束后恢复位置；运行时保持桌面解锁且不要操作鼠标。原生 DPI 测试使用自有窗口和内存配置，不发送外部鼠标键盘输入，不更改系统缩放或开机启动。
